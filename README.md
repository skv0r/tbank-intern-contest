## О задачах

1. **Равные суммы** — можно ли разбить массив из `n` чисел на `n − 1` множеств с одинаковой суммой.
2. **Частые строки** — все строки, которые встречаются чаще всего, вывести по алфавиту.
3. **Бинго** — на поле `n × n` зачёркивают клетки; найти первый раунд, когда собралась линия (строка, столбец или диагональ).
4. **Перестановка с k инверсиями** — построить перестановку `1…n` ровно с `k` инверсиями.
5. **k-й продукт пар** — среди произведений всех пар `a[i] * a[j]` (`i < j`) найти k-й в отсортированном порядке.
6. **Турнир стажёров** — олимпийская сетка из `2^n` человек, можно выбирать победителей матчей; максимизировать сумму выплат за число побед.
7. **Динамический MST** — к дереву по одному добавляют рёбра, после каждого запроса — вес минимального остовного дерева.
