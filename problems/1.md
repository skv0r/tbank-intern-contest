# Задача 1 · 100 баллов · 1 секунда · 256 МБ

Дан массив `a` длины `n`. Можно ли разбить его на **n − 1** множеств так, что:

- каждый элемент попадает ровно в одно множество;
- сумма чисел в каждом множестве одна и та же.

## Вход

```
n
a1 a2 ... an
```

- `n` — длина массива, от 3 до 10
- каждое `ai` — целое от 1 до 100

## Выход

`YES`, если такое разбиение есть, иначе `NO`. Регистр не важен: `yEs` тоже сойдёт.

## Пример 1

Ввод:

```
4
1 2 1 2
```

Вывод:

```
YES
```

Множества: `{1, 1}`, `{2}`, `{2}` — сумма в каждом равна 2.

## Пример 2

Ввод:

```
4
6 7 6 9
```

Вывод:

```
NO
```
