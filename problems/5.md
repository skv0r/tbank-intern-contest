# Задача 5 · 100 баллов · 2 секунды · 256 МБ

Дан массив `a` длины `n`. Берутся все пары элементов с разными индексами `i < j`, и для каждой считается произведение `a[i] * a[j]`.

Получается список из `n·(n−1)/2` произведений. Его сортируют по возрастанию. Нужно найти **k-й** элемент этого списка (нумерация с 1).

Все пары в память не влезут: при n = 200 000 их около 20 миллиардов. Нужен алгоритм без явного списка.

В массиве бывают нули и отрицательные числа. Произведения до 10^18.

## Вход

```
n k
a1 a2 ... an
```

- `n` от 2 до 200 000
- `k` от 1 до n·(n−1)/2
- каждое `ai` от −1 000 000 000 до 1 000 000 000

## Выход

Одно число — k-й элемент отсортированного списка произведений.

## Примеры

Для массива `2 2 8 0 -6 -9` все 15 произведений после сортировки:

```
-72, -48, -18, -18, -12, -12, 0, 0, 0, 0, 0, 4, 16, 16, 54
```

9-й элемент — `0`, 4-й — `-18`.

Ввод 1:

```
6 9
2 2 8 0 -6 -9
```

Вывод 1:

```
0
```

Ввод 2:

```
7 20
3 2 2 -6 -7 0 0
```

Вывод 2:

```
6
```

Ввод 3:

```
6 4
2 2 8 0 -6 -9
```

Вывод 3:

```
-18
```
